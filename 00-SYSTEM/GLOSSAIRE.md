# 📖 GLOSSAIRE — Termes du Bot

## 🪙 Trading

| Terme | Définition |
|-------|------------|
| **Sniping** | Achat instantané au lancement d'un token (block 0) |
| **Rugger** | Token créé pour arnaquer les investisseurs |
| **Block 0** | Premier bloc de la transaction (achat immédiat) |
| **Block 0+1** | Deuxième bloc (légèrement plus tard) |
| **TP** | Take Profit — objectif de gain |
| **SL** | Stop Loss — limite de perte |
| **PnL** | Profit and Loss — gain/perte totale |
| **Martingale** | Augmenter le montant après une perte (INTERDIT) |
| **Tilt** | État émotionnel qui fait trader mal |

## 🤖 Bot Fproject

| Terme | Définition |
|-------|------------|
| **MCP** | Model Context Protocol — connecteur Claude ↔ Bot |
| **Brain** | Module d'analyse du bot |
| **Compétences** | Outils spécifiques du bot (analyse on-chain, etc.) |
| **Copytrade** | Copier les trades d'un autre wallet |
| **Pump.fun** | Plateforme de création de memecoins sur Solana |

## 🧠 Claude / IA

| Terme | Définition |
|-------|------------|
| **Hallucination** | Quand l'IA invente des faits faux |
| **Token** | Unité de texte consommée par Claude (coûte de l'argent) |
| **Context window** | Mémoire temporaire de Claude (se vide à chaque session) |
| **Prompt système** | Instructions de base données à Claude |
| **Vault** | Dossier Obsidian = base de connaissances |
